建岛理念 01

一

少，但有回声

把界面删到只剩必要，再留一处让人心动的细节。删减不是目的，回声才是——好东西会在你关掉页面之后继续响一会儿。

二

慢，但不锈

这座岛不追热点，更新以「月」为单位。但我希望十年后打开这里，代码依然能跑，句子依然诚恳——像礁石，而不是浪花。

三

小，但完整

与其做一个庞大的半成品，不如做一颗打磨过的小行星。每个项目都自己站得起来，自己解释自己。

「我们建造的东西，最终会反过来塑造我们。所以我谨慎地挑选要建造什么。」

精选作品 02

Web App2026

Tidepaper 潮汐纸

一个把每日新闻摘要排版成「潮汐曲线」的阅读器：重要的事涨成波峰，琐碎的退向滩涂。深色低光界面，滚动时有真实的波浪阻尼。

TypeScript · Canvas进行中
开源库2026

lumen.css

4KB 的极简 CSS 框架。没有构建步骤，没有类名咒语，只有暗色变量、渐变工具类和克制的微动效。设计信条：加载它的时间，应该比考虑要不要用它的时间短。

CSS · 无依赖v0.3
实验2025

Orbit 轨道

三体风格的引力沙盒。拖拽一颗行星，看着它的轨道被实时重写，直到某个天体被甩出星系。它教会我的事：稳定从来不是宇宙的默认状态。

JavaScript · 物理已归档
写作2025

《低光设计手册》

一篇关于暗色界面的长文：为什么深色模式不是「把颜色反过来」，层级如何靠亮度而非靠阴影，以及那个经典的陷阱——纯黑背景上的纯白文字会让人眼晕。被几个设计周刊转载。
