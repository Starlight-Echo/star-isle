01 建岛理念

一

少，但有回声

把界面删到只剩必要，再留一处让人心动的细节。删减不是目的，回声才是——好东西会在你关掉页面之后继续响一会儿。

二

慢，但不锈

这座岛不追热点，更新以「月」为单位。但我希望十年后打开这里，代码依然能跑，句子依然诚恳——像礁石，而不是浪花。

三

小，但完整

与其做一个庞大的半成品，不如做一颗打磨过的小行星。每个项目都自己站得起来，自己解释自己。

「我们建造的东西，最终会反过来塑造我们。所以我谨慎地挑选要建造什么。」

05 常见问答

这是一个测试网站吗？

是的。本站仅用于网页设计与前端开发实验，全部内容（项目、文章、邮箱）均为虚构演示，不代表任何真实的人物、组织或服务。

网站是用什么做的？

纯手写 HTML / CSS / JavaScript，零框架、零构建、零依赖，托管在 GitHub Pages 上。整个站点不到 30KB。

导航里的下拉菜单是怎么实现的？

用 CSS :hover / :focus-within 实现的二级玻璃拟态下拉面板，配少量 JS 处理移动端点按展开。你可以把鼠标悬停在「作品」「关于」上试试。

可以参考或复用这里的代码吗？

可以。这是一个公开的学习实验，代码就在 GitHub 仓库里，欢迎 fork 和改造。
